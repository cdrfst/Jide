# Jide（记得）

个人任务管理 + 到期提醒应用。说一句话，它就记得，并在到点时提醒你。

## 目标平台

Windows 桌面、安卓；iOS 以后再做。

## 技术栈

Flutter（Dart）+ drift（SQLite）+ riverpod。后期接入 AI 接口，用自然语言生成任务。

## 状态

设计阶段，尚无代码。进度见 `docs/PROGRESS.md`。

## 文档

- `CLAUDE.md`：AI 协作入口与工作规则
- `docs/DESIGN.md`：总体设计与选型
- `docs/DECISIONS.md`：决策记录
- `docs/PROGRESS.md`：进度与交接

## 运行

待 Flutter 环境就绪、工程生成后补充。
