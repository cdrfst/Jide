## ADDED Requirements

### Requirement: 内置智能清单
系统 SHALL 提供今天、明天、最近 7 天、收集箱四个内置智能清单，它们按条件动态汇总任务，不拥有任务。

#### Scenario: 今天清单
- **WHEN** 用户打开今天清单
- **THEN** 列出截止日为今天的未完成任务，以及已逾期的未完成任务

#### Scenario: 收集箱
- **WHEN** 用户打开收集箱
- **THEN** 列出所有未指定清单的未完成任务

### Requirement: 按用户时区划分日期
系统 SHALL 按用户当前时区划分"今天"和"明天"的边界。

#### Scenario: 跨午夜
- **WHEN** 时间从 23:59 走到次日 00:00
- **THEN** 原来属于"明天"的任务进入"今天"清单
